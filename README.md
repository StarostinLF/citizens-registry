# Картотека граждан

Система учёта граждан и ведения личных дел.

## Функционал

### Информационно-аналитический дашборд

- **KPI-метрики**: общее количество граждан (и средний возраст), новые постановки за месяц (с динамикой к прошлому месяцу), доля активных дел («На учёте»), суммарное число открытых обращений.
- **Интерактивная аналитика**:
  - Динамика постановки на учёт за последние 12 месяцев.
  - Распределение по статусам учёта.
  - Возрастные группы и распределение по полу.
  - Топ-8 регионов по численности.
  - Распределение по социальным/льготным категориям.
- **Быстрая навигация**: клик по сегменту графика или KPI-карточке перенаправляет в реестр с автоматически применённым фильтром.
- **Оперативные виджеты**: дни рождения на ближайшей неделе и последние поставленные на учёт граждане.

### Реестр картотеки

- **Виртуализация и производительность**: виртуализированный скроллинг (`@tanstack/react-virtual`) для работы со 100 000 записей.
- **Фильтрация и поиск**:
  - Поиск по ФИО с дебаунсом.
  - Фильтрация по статусам, полу, регионам, категориям учёта и диапазону возраста.
- **URL-параметры**: поиск, фильтры, сортировка и пагинация хранятся в query-параметрах URL — ссылками на выборку можно делиться.

### Карточка гражданина

- **Профиль и статус**: шапка с ключевыми реквизитами, статусом, категорией и возрастом.
- **Около 150 параметров учёта**: 12 логических блоков (персональные данные, паспорт, адреса регистрации и проживания, семья, образование и занятость, доходы, здоровье, льготы, воинский учёт, коммуникация, служебная информация).
- **20 связанных разделов**: семья, образование, работа, льготы, выплаты, документы, обращения, адреса, имущество, транспорт, воинский учёт, инвалидность, медицина, доходы, жильё, соцуслуги, судебные дела, вложения, приёмы, история контактов.
- **Ленивая загрузка**: связанные таблицы подгружаются через `TanStack Query` с кэшированием.
- **Боковая панель**: быстрые переходы по разделам со счётчиками записей, контакты и история событий.

## Стек технологий

- **Фреймворк и UI**: React 19, TypeScript, Vite.
- **Стилизация**: Tailwind CSS v4, Lucide React, Geist Font.
- **Компоненты интерфейса**: shadcn/ui, Base UI (`@base-ui/react`), cmdk, Sonner.
- **Виртуализация**: TanStack Virtual v3.
- **Работа с сервером и кэш**: TanStack Query v5.
- **Формы**: React Hook Form v7.
- **Графики**: Recharts v3.
- **Маршрутизация**: React Router DOM v7.
- **Генерация мок-данных**: детерминированный сидированный генератор на 100k записей (`@faker-js/faker`).

## Запуск

### Установка зависимостей

```bash
  npm install
```

### Запуск в режиме разработки

```bash
  npm run dev
```

### Сборка для продакшена

```bash
  npm run build
```

### Проверка линтером и форматирование кода

```bash
  npm run lint
```
